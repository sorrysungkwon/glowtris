# Glowtris Design System
- Glowtris design. Cyberpunk wireframe.
- Golden rule: No hardcode. Use token always.
- Brand colors: cyan, purple, pink.
- Game modes get one color. Marathon green. Sprint cyan.
- Font: Orbitron for game text. Pretendard for read text.
- Shape: 4px grid. Corners round. 4px small, 9999px pill.
- Shadow: flat to bright neon glow. 5 levels.
- Touch: hover go up, glow big. Click go small, go down.
- Light/Dark mode: switch token, not file.
